
# Auspify Technologies – Data Analysis Using Python

## Internship Project

This repository contains four completed tasks as part of my Data Analysis Using Python internship at Auspify Technologies.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- VS Code
- Jupyter Notebook
- CSV Dataset

## Tasks Completed

### Task 1: Netflix Data Cleaning and Preparation
- Loaded the Netflix dataset.
- Checked missing values and duplicate records.
- Cleaned and prepared the dataset.
- Saved the cleaned dataset.

### Task 2: Content Type Analysis
- Analyzed Movies and TV Shows.
- Calculated content percentages.
- Created bar and pie charts.
- Identified the most common content type.

### Task 3: Country-Wise Netflix Content Analysis
- Analyzed Netflix content by country.
- Separated multiple countries.
- Identified the top 10 countries.
- Created a bar chart.

### Task 4: Trend Analysis by Release Year
- Analyzed Netflix content by release year.
- Identified the year with the highest number of titles.
- Created a release-year trend chart.
- Exported yearly content counts.
